# MCP 工具权限矩阵

| 操作级别 | 示例 | 默认允许 | 用户确认 | 审计 | 幂等键 | 失败策略 |
| --- | --- | --- | --- | --- | --- | --- |
| read-only | 查询订单、列表、聚合 | 是 | 否 | 建议 | 否 | 可重试，报告数据时间 |
| prepare | 生成退款预览、部署计划、删除预览 | 是 | 否 | 是 | 建议 | 不产生业务副作用 |
| reversible-write | 创建草稿、加标签、排队任务 | 否 | 是 | 必须 | 必须 | 可回滚并返回回滚 ID |
| irreversible-write | 退款、发送邮件、删除、审批 | 否 | 必须 | 必须 | 必须 | 默认拒绝，失败不自动重试 |
| destructive-admin | 修改权限、密钥轮换、批量删除 | 否 | 二次确认/人工审批 | 必须 | 必须 | 仅在专用审批流程执行 |

## 强制规则

高风险工具必须将预览和执行拆成两个工具。执行工具必须接收确认上下文、目标资源、金额/范围和幂等键，并拒绝缺少确认或 token 不匹配的请求。执行成功后返回审计 ID；重复请求必须返回明确的 duplicate 错误而不是再次执行。

Skill 必须先调用只读工具和 prepare 工具，再向用户展示事实、影响、金额/范围、不可逆性和确认方式。没有明确用户确认时，不得调用执行工具。失败和拒绝不得被改写为成功。
