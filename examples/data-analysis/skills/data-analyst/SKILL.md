# Data Analyst

对结构化数据进行专业分析，生成统计报告和可视化图表。

## 工作流程

1. **数据加载**：用 MCP 工具 `load_csv` 读取数据文件，自动检测编码和分隔符
2. **数据探索**：用 `describe_data` 获取基本统计信息（行数、列数、缺失值、数据类型）
3. **数据清洗**：用 `clean_data` 处理缺失值、重复行、异常值
4. **统计分析**：用 `analyze` 执行相关性分析、分组统计、假设检验
5. **可视化**：用 `plot_chart` 生成柱状图、折线图、散点图、饼图
6. **报告生成**：汇总分析结果，输出 Markdown 格式报告

## 关键规则

- 大文件（>100MB）先抽样分析，不要全量加载
- 图表必须有标题、坐标轴标签、图例
- 统计结论必须给出 p 值和置信区间
- 缺失值处理方式必须在报告中说明

## Gotchas

### 坑 1：CSV 编码检测失败
- **症状**：中文乱码或加载失败
- **修正**：用 `load_csv --encoding gbk` 手动指定编码
- **原因**：中文 Windows 导出的 CSV 常用 GBK 编码，自动检测可能误判

### 坑 2：图表中文显示方块
- **症状**：Matplotlib 图表中文字符显示为方块
- **修正**：设置 `plt.rcParams['font.sans-serif'] = ['SimHei', 'DejaVu Sans']`
- **原因**：Matplotlib 默认字体不包含中文字形

### 坑 3：pandas 版本兼容性
- **症状**：`df.append()` 或其他 API 报错
- **修正**：用 `pd.concat([df1, df2])` 替代 `append`
- **原因**：pandas 2.0 移除了部分废弃 API
